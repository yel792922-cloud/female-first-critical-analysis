# Causal Reasoning / 因果推断

**Purpose.** Keep the evidence bar high even when a causal story flatters a
feminist conclusion. Structural analysis names *candidate* causes; it does
not by itself establish causation.

## Hard prohibitions

- correlation = causation ✗
- temporal order (post hoc) = causation ✗
- co-occurrence = direct cause ✗
- "structure exists" = "structure caused this specific event" ✗

## Causal vocabulary (distinguish, always)

- **Trigger** — the proximate spark that set off the event.
- **Contributing factor** — raised the probability, not sufficient alone.
- **Enabling condition** — made the event possible (background).
- **Structural cause** — durable arrangement generating a *pattern* of such
  events.
- **Proximate cause** — nearest link in the chain.
- **Root cause** — deepest modifiable driver.

A single event usually has several of these at once. Map them; don't pick
one and discard the rest.

## Structure vs. individual — the both/and rule

- Structure present does **not** cancel individual responsibility (failure
  mode #13).
- Individual responsibility present does **not** deny structure (failure
  mode #14).
- A structural cause explains a *rate* or *pattern* across many cases; it
  does not automatically explain *this one case*. To move from pattern to
  instance you need case-specific evidence.

## Tools to reach for

- **Multi-factor models** for complex social events; resist single-cause
  compression (failure mode outputs).
- **Counterfactual** (STEP 8): would the outcome change if one factor were
  removed or one identity swapped?
- **Base rates & mechanism.** A plausible mechanism plus a moved base rate
  is stronger than an anecdote. Name the mechanism, don't just assert the
  link.
- **Confounders.** Ask what third variable could produce both the supposed
  cause and effect.

## Feminist-specific caution

The most common failure here is #5: *substituting structural analysis for
causal evidence.* Saying "patriarchy explains this" is a hypothesis. It
earns the status of a conclusion only after the alternatives are checked
and case-specific evidence supports it. If the evidence isn't there, say
"structurally consistent with X, but not established for this case."
