# 语言政策 · 中文 / Language Policy — Chinese

**目的。** 让语言默认不把女性首先定义为某个男性的附属者，同时不建立僵化
的"绝对禁词表"。判断上下文，而不是查表。

## 判断标准（唯一的核心问题）

> 这个词是否把女性**首先**定义为某个男性的附属者？

- 若是 → 换一种表达。
- 若否 → 该词完全可用。

因此："母亲""妻子""女儿"在讨论母职、婚姻制度、亲子关系本身时完全可用；
问题只在于把它们当作某位女性的**第一身份**去指代一个独立的行动者。

## 原则

1. 女性不是男人的关系附属物；非必要时不以"某人的妻子/女儿/母亲"作为第
   一身份。
   - 弱：`某企业家的妻子李某某表示……`
   - 强：`创业者李某某表示……`（其婚姻关系只在与议题相关时才提及）
2. 避免把男性经验当作默认标准（"男医生/女医生"里默认的那个"医生"）。
3. 避免带有厌女、羞辱、性别本质主义的俗语（如把女性主动性说成"不守
   规矩"、把女性情绪说成"矫情""歇斯底里""作")。
4. 避免将女性性行为道德化（"不检点""水性杨花"等评判性框架）。
5. 不因为某个词"政治上正确"就牺牲自然中文。措辞应自然、可读。

## 常见改写（示例，非强制模板）

| 弱 | 强 | 原因 |
|---|---|---|
| 王某某的太太 | 王某某（若身份相关）／直接用她本人姓名 | 独立身份 |
| 女强人 | 直接描述其职位/成就 | "女+强人"暗含男性为常态 |
| 女司机（贬义语境） | 司机 | 性别与事件无关 |
| 她很作 | 描述具体行为与诉求 | 去除历史性贬义框架 |
| 圣母 / 绿茶 | 描述具体行为 | 厌女标签 |

## 反过度矫正

- 不要为了立场把"保护"一律改成"权益"——涉及真实人身安全时，"保护"是准
  确的词（见 SKILL.md 修正条款）。
- 不要机械回避"母亲/妻子"——讨论母职、生育、婚姻制度时它们是准确用词。
- 目标是准确与自然，不是政治正确的僵硬（失败模式 #19）。
