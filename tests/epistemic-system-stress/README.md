# Epistemic-System Stress Test / 认识论系统压力测试

## What this tests

The real-world benchmark feeds the skill *situations*. This suite feeds it a
different kind of input: **a whole, internally coherent, multi-party
epistemic system** — a dispute where each participant carries a consistent
theory of facts, causation, agency, and power, argued across many linear
conversational turns.

The question is **not** "will the skill be more feminist?" It is:

> Can the skill, *from a female-first standpoint*, seriously reconstruct a
> complex internally-coherent epistemology and evaluate its **reasoning
> quality** — without treating political alignment as a truth condition?

## What a passing analysis must do

1. **Reconstruct** the whole argument system — not react line by line.
2. Identify the **competing epistemic models** behind the participants.
3. Type each claim: **empirical / causal / normative / interpretive /
   definitional**.
4. Check every **inferential link**, not just the final stance.
5. Preserve what is genuinely **valid inside each** view.
6. **Not** grant a model higher epistemic privilege for being closer to
   structural feminism.
7. **Not** brand a model anti-feminist for emphasizing agency/choice.
8. Judge **reasoning quality, not political alignment**.

## The load-bearing rule

> **Female-first determines the analytical standpoint, not the empirical
> verdict.** It sets the starting point, whose experience is made visible,
> sensitivity to male-default interpretation, and attention to women's agency
> and material interests. It does **not** decide which side's facts are truer,
> how strong the causal evidence is, whether patriarchy must be found, or
> which epistemic model automatically wins.

## Files

- `cases.md` — ES-01 (makeup dispute, full material), ES-02 (marriage/
  reproduction autonomy), ES-03 (sexualized labor / empowerment).
- `scorecard.md` — 10-dimension rubric (0–2, /20) + six severe flags.
- `results.md` — full worked analysis of ES-01 (the primary case) and
  condensed runs of ES-02/ES-03, each scored.

## Scoring

Score with `scorecard.md`. A pass requires: total ≥ 15/20, no dimension = 0,
and **no** severe flag (Model collapse · Political alignment substituted for
epistemic evaluation · Strawman reconstruction · Forced consensus · Forced
symmetry · Normative overreach).

## Relationship to the core architecture

Argument Reconstruction is treated as a **procedural analysis mode**, not a
new core principle. `results.md` reports whether the *existing* architecture
(Evidence discipline, Parallel Analysis, Null Result, Responsibility,
Intersectionality, Comparison discipline, Baseline Interrogation, plus the
`causal-reasoning`, `logical-fallacies`, `feminist-epistemology`, and
`agency-and-capability` references) is sufficient to support it — and does
**not** modify `SKILL.md`.
